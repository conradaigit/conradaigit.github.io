Privacy Policy

AI Lab Workspace Backup is a private, personal utility used only by its owner.

Google user data

  • The utility accesses Google Drive using the drive.file permission, which covers only files the utility itself creates or that are explicitly opened with it.
  • Google user data is used only to carry out the owner's own backup and storage operations.
  • The utility does not sell Google user data, does not use it for advertising, and does not intentionally disclose it to third parties.
  • Authentication credentials are used only to authorize the backup function.

No public service

No public user accounts or public service are offered.
